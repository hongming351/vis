# 《可视化导论》课程门户

零依赖的静态课程门户。**新版「温暖编辑式学习空间」**：首页是 5 章错位卡片墙 + 学习路径节点图，点击进入可逐步执行的课程页（逐行高亮 + 变量面板 + 控制台 + 练习自检 + 小测验）。**旧版** 5 章页面（讲解 / 关键代码 / 演示 三 tab）保留可访问，并通过换皮层统一了视觉风格。

## 📄 汇报材料

- `docs/讲稿.md` —— 课程大作业答辩讲稿（做了什么 / 创新点 / 成果数据 / 现场演示脚本）

## ▶️ 本地启动

```bash
cd vis
python -m http.server 8080

# 浏览器打开
# 新版首页：http://localhost:8080/
# 新版课程页：http://localhost:8080/lesson.html?c=c1&l=c1-1
# 旧版第 1 章：http://localhost:8080/lesson-01/
```

> 由于旧课页通过 `fetch` 加载 CSV，需走 HTTP（不能用 `file://` 直接双击打开）。新版首页与课程页不请求任何数据文件，`file://` 亦可打开。

## 🛠️ 技术栈

- 零打包：纯 HTML + CSS + JS，无构建步骤
- 零依赖：D3.js v7 **本地 vendored**（`vendor/d3.min.js`，离线可用）；新版课程页不依赖 D3
- 单页静态站点：`python -m http.server` 默认启动方式
- 学习进度存 `localStorage`（key：`warm-progress-v1`），不上传任何数据

## 🎯 设计原则

1. **案例为中心**：每个理论点都嵌入用户的实践案例
2. **代码可逐步执行**：每节课的示例都能一行一行跑，变量面板实时反映作用域变化
3. **文字与内容优先**：装饰克制、大量留白、正文行宽 44–56 字符
4. **零安装**：学生无需装任何东西，浏览器打开即用
5. **单一内容源**：`courses.js` 一个 `COURSES` 数组驱动首页卡片、路径图与全部课程页

## 🆕 温暖编辑式学习空间（新版）

- **设计令牌**：纸色 `#F4F0E8` / 卡片白 `#FFFFFF` / 主墨 `#161513` / 强调橙 `#E4572E` / 辅助绿 `#2E6B4F` / 代码底 `#1B1917`
- **字体**：标题 Fraunces / Noto Serif SC，正文 Inter / Noto Sans SC，代码 JetBrains Mono
- **Hero**：超大衬线标题 `clamp(2.9rem, 12vw, 10.5rem)`，中英混排
- **课程卡片**：12 列错位网格，高低不齐；悬停上浮加深阴影、封面放大 1.07、底部浮出课程名 / 课时 / 难度
- **进度环**：SVG 圆环，已完成部分用强调橙
- **学习路径**：节点横向排列、虚线连接，点击展开详情
- **自定义光标**：圆环 + 圆点，`mix-blend-mode: difference`，悬停链接时圆环放大
- **滚动显现**：`IntersectionObserver`，逐项延迟；遵循 `prefers-reduced-motion`

## 🆕 课程页（逐步执行）

- **行级注释**：悬停左侧行号显示该行在做什么
- **变量面板**：名称 / 类型 / 值，数组用方块可视化，变量变化时卡片闪动
- **控制台**：`console.log` 输出逐条出现
- **键盘步进**：`→` 下一步，空格自动播放
- **循环上限**：循环体只在前两轮暂停，避免上百次点击
- **练习区**：可编辑代码 + 自动检查（3–4 项断言，逐项给出期望值与实际值）
- **小测验**：点击选项立即反馈并显示解析
- **上一节 / 下一节**：底部导航，跨章节连续

### 全局课堂笔记（右侧停靠）

- **五章共用同一份笔记**：文字存 `localStorage`（key `warm-notes-v1`），图片存 `IndexedDB`
- **可附图片**：点「＋ 附图片」选图，或直接 **Ctrl+V 粘贴截图**；两者都会先用 canvas 压缩（最长边 1400px、JPEG 0.72），
  缩略图网格展示，点击放大、悬停出删除。剪贴板里只有文字时不拦截，文字粘贴照常工作；面板收起时粘贴会自动展开
- **开合按钮**：右侧边缘竖排把手「笔记」，点一下展开 / 收起；宽屏展开时布局变三列（内容让位而非被遮挡），
  容器同时放宽到 1480px、内边距收到 18px，让面板贴近屏幕右缘；
  窄屏（<1180px）自动改为覆盖式抽屉；开合状态持久化（key `warm-notes-open`）
- **快捷键**：`Esc` 关闭大图预览 / 收起面板
- 全部数据只存在本机浏览器，不上传

### 课程仪表板（左侧目录底部）

- **五等分圆环**，一章一段；学完一章（该章全部小节勾选完成）点亮一段，未点亮为白色
- 段落配色：橙 `#E4572E` → 赭 `#C9852B` → 绿 `#2E6B4F` → 蓝 `#3D5A80` → 梅 `#7B4B6B`
- 圆心显示已学完章节百分比；下方五个小圆点同步点亮，悬停显示章名
- **五章全部学完**时撒一次彩带（Canvas，6 秒，末段淡出），并在仪表板下方显示「🎉 恭喜学完本课程」
- 彩带只撒一次（`localStorage` key `wbl-course-celebrated`）；仪表板下方有「重置进度」可重新体验
- 遵循 `prefers-reduced-motion`：不撒彩带
- 章节清单与总数集中在 `shared/course.js`，**增删小节时要同步改这里的 `total`**
